# Cryptocalc

Утилита позволяет посчитать, сколько денег вы могли бы заработать / потерять, если бы регулярно покупали крипту.
Данные собираются из архива данных Binance, авторизация для их загрузки не требуется. 

## Сборка

* Нужен go версии 1.23 или выше
* Склонируйте репозиторий в удобное место
* Выполните `make build` в корне репозитория
* По желанию исполняемый файл cryptocalc можно положить куда-то в `$PATH`

## Запуск

* `./cryptocalc` запустит рассчет с настройками по-умолчанию(посмотреть их можно в `./cryptocalc --help`)
* `./cryptocalc --help` покажет, какие параметры можно настроить, чтобы получить более релевантные для себя результаты
