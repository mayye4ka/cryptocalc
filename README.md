#Cryptocalc

Сервис для расчета потенциальной финансовой выгоды/убытка при регулярной (ежедневно, еженедельно, ежемесячно) покупке криптовалют на желаемую сумму в удобное время. 
Для оценки выгоды также рассчитываются общие затраты на покупку и потенциальный заработок в случае регулярного открытия банковских вкладов на аналогичную сумму со ставкой 5%.
Данные о стоимости токенов собираются с помощью Binance Data Collection 

##Запуск
Для запуска выполните ***make build.*** Команда ***./cryptocalc --help*** выведет флаги/опции, которые необходимы для расчета потенциальной выручки.

###Планы

- [ ] Возможность покупки в разное время в разные дни
- [ ] Возможность сравнения с инвестициями в s&p 500
